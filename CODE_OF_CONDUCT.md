# Code of conduct

## Our standard

Project spaces should be respectful, constructive, and safe for people of all
backgrounds and experience levels.

Positive participation includes giving actionable feedback, discussing ideas
rather than people, acknowledging mistakes, and respecting project boundaries.

Harassment, discrimination, threats, deliberate disruption, publication of
private information, and abusive or sexualized conduct are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers through the
verified PlatanoGames GitHub profile. Maintainers may edit or remove content,
limit participation, or ban contributors when necessary to protect the project
community.

Good-faith technical disagreement is welcome. Personal attacks are not.
